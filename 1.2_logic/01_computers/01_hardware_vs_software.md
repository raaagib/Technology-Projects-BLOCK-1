# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware refers to the physical parts of a computer or electronic device that you can see and touch. Examples of hardware include the keyboard, mouse, monitor, printer, motherboard, hard drive, and processor (CPU). Hardware works together to help a computer perform different tasks, such as processing information, storing data, displaying images, and playing sounds. Unlike software, which consists of programs and instructions, hardware is made up of physical components. Both hardware and software are important for a computer to function properly.

## Explain Software
Write **at least 50 words** explaining what software is.
Software is a collection of programs and instructions that tell a computer or electronic device what to do. Unlike hardware, software cannot be physically touched because it is made up of code and digital information. Examples of software include operating systems such as Windows, applications such as Microsoft Word, web browsers such as Google Chrome, and games. Software helps users perform tasks such as writing documents, browsing the internet, editing pictures, and playing music. Hardware and software work together to make a computer function properly.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software interact to make a computer or electronic device work properly. Hardware refers to the physical parts of a computer, while software consists of the programs and instructions that tell the hardware what to do. For example, when you type on a keyboard, the software receives your input and displays the words on the monitor. The processor executes software instructions, while memory and storage help hold data and programs. Hardware and software depend on each other to perform tasks efficiently and allow users to use computers for different purposes.
