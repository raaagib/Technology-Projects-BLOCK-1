# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Executes instructions and performs calculations for programs|Model, number of cores and threads, clock speed (GHz), socket type and power/thermal rating. |
| RAM | Temporarily holds data and instructions that programs are actively using.| Capacity (GB), type (DDR4/DDR5), speed (MT/s) and number of modules.|
| Storage |Permanently stores the operating system, applications and files. |Type (SSD/HDD), capacity (GB/TB), interface (SATA/NVMe) and read/write speed. |
| Motherboard |Connects the components and enables them to communicate. |Form factor (ATX/micro-ATX/mini-ITX), CPU socket, RAM support and expansion slots. |
| Power Supply |Converts mains electricity into regulated power for computer components | Rated output (W), efficiency certification, connectors and modularity.|
| Cooling |Removes heat to prevent overheating and maintain performance. |Type (air/liquid), fan size (mm), cooling capacity and noise level (dBA). |
